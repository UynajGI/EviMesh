## 1. 全状态矩阵

每个数据驱动页面必须同时具备五态：loading / empty / error / denied / 离线。组件与文案基线如下。

### 1.1 状态组件基线

| 状态 | 组件 | 构成 |
|---|---|---|
| loading | `.skeleton` | 形状与最终布局一致的骨架（title 60% 宽、text 90%/70%、badge、row）；微光动画在 reduced-motion 下静止 |
| empty | `.blank` | 图标圆（muted 底）+ 标题（18px/600）+ 说明（14px muted，≤42ch）+ 动作按钮（给出第一条可执行路径） |
| error | `.blank--error` | 同上 + danger 语义 + request id（mono 12px subtle）+ 重试按钮（icon-arrows-clockwise） |
| denied | `.blank` 变体 | icon-lock + 「需要权限」标题 + 说明缺失的 scope 或可见性 + 「请求访问 / 联系所有者」动作（或说明为何不可请求） |
| 离线 | `.alert--warning` 横幅 | 置于内容顶部：「当前离线，显示的是最近一次成功加载的数据」+ 数据时间戳；恢复后自动消失 |

### 1.2 页面类型 × 状态矩阵

| 页面类型 | loading | empty | error | denied | 离线 |
|---|---|---|---|---|---|
| Home watchlist | 3 条变化行骨架 | 「还没有关注任何研究」+ 去 Explore | 变化流加载失败 + request id + 重试 | （登录态页面）未登录引导去登录 | 显示缓存 + 时间戳 |
| Explore 结果 | 结果卡骨架 ×4 | 「没有匹配的研究」+ 建议放宽筛选词 | 搜索失败 + 重试 | 私有对象不出现在结果中（无需 denied 态） | 提示离线不可搜索 |
| Work 队列 | 队列行骨架 | 「当前没有待办」+ 去 Explore 找可参与项 | 队列加载失败 + 重试 | 无权处理的项不显示 | 缓存只读 |
| Claim / Question 详情 | 主卡 + meta 骨架 | 不适用（对象存在才进详情；404 走 error） | 对象加载失败 + 重试 + request id | 「该对象私有」+ 说明可见性级别 | 缓存只读 + 时间戳 |
| DAG 图 | 图区域骨架 | 「该主张暂无关系边」+ 列表视图仍可用 | 图数据失败 + 重试；列表视图独立重试 | 同详情 | 缓存只读 |
| Agent 连接中心 | 步骤骨架 | 「还没有连接任何客户端」+ 第一步动作（选择客户端） | 连接测试失败：原因 + 重试 + 撤销入口 | Token scope 不足：列出缺失 scope | 连接状态显示「离线」 |
| Token 列表 | 行骨架 | 「还没有 Token」+ 创建入口（说明设备授权优先） | 加载失败 + 重试 | （本人页面，不适用） | 只读 |
| 表单（向导 / 提交） | 提交按钮 loading 态，表单可编辑 | 不适用 | 提交失败：字段级错误（行内 danger 文本）+ 顶部 alert-danger 概述 + 保留已填内容 | scope 不足时禁用提交并说明 | 草稿存本地，提示恢复 |
| 验证流程 | 分步骨架 | 不适用 | 校验失败行内提示；blind 边界警示用 alert-warning | 无权验证：说明所需角色 | 不允许提交，仅草稿 |

## 2. 空状态文案原则

1. 结构固定：「现状一句话」+「为什么是空的（可选）」+「下一步动作」。
2. 必须可执行：每个空状态至少给一个按钮或链接，指向填充它的具体动作。
3. 用自然语言层词汇（问题、主张、证据、验证、质疑、快照），不用数据库对象名。
4. 不假装热闹：没有数据时不用演示数据冒充实时内容；演示数据必须标注。
5. 不制造焦虑：不写「你落后了」「别人都在做」类措辞；change level 只表注意优先级。
6. 长度：标题 ≤ 12 字（中文），说明 ≤ 42 字符宽度两行。

## 3. 错误恢复与 request_id

1. 所有 API 错误经统一映射转为可读文案（超时 / 离线 / 401 / 403 / 404 / 5xx 各有固定措辞），原始 API 错误、堆栈、表名、路由一律不外露。
2. 每个错误态显示 `request id`（mono、12px、fg-subtle），格式如 `request id: req_7f3a9c2e41b8`，可复制。
3. 恢复路径按错误类型固定：
   - 超时 / 5xx：重试按钮（保留当前上下文与已填数据）。
   - 401：「会话已过期」+ 重新登录入口（登录后回到当前页）。
   - 403：说明所需权限 + 请求路径。
   - 404：「对象不存在或已被撤回」+ 解释 revision 与撤回语义（撤回不等于删除历史）。
   - 离线：离线横幅 + 只读缓存。
4. 重试必须保留筛选、展开状态与滚动位置。

## 4. WCAG 2.2 AA 检查单

颜色与对比：

- [ ] 所有文本 token 对双主题 ≥ 4.5:1（第 02 章全表实测）。
- [ ] 非文本元素（焦点环、输入框边框、图标按钮图形）对相邻表面 ≥ 3:1。
- [ ] 颜色不是唯一信息载体：徽标有文本，DAG 边有线型与标签，状态变化有图标或文字。

键盘与焦点：

- [ ] 焦点环 2px、`focus-visible`、outline-offset 2px，在浅色卡片、深色底、实底徽标上均可见。
- [ ] 键盘焦点不被粘性 Header 或浮层完全遮挡（SC 2.4.11）。
- [ ] Dialog 焦点管理：进入聚焦首个可交互元素，Esc 关闭，关闭后焦点回到触发元素。
- [ ] DAG 图必须提供键盘可达的列表等价视图（Graph / List 切换），选中节点上下文在两个视图间保留。

目标尺寸与触控：

- [ ] 指针目标 ≥ 24×24 CSS px（SC 2.5.8）；主要交互控件按 44px 目标设计（control-h-lg）。
- [ ] 移动端行高 ≥ 44px；图标按钮命中区不小于 32px（密集表格内例外，需间距补偿）。

语义与读屏：

- [ ] 页面标题（document.title）随路由变化；每页恰好一个 h1。
- [ ] 徽标与状态的文本标签可被读屏读取；装饰图标 aria-hidden，含义图标带 aria-label。
- [ ] 表单 label 在上、错误在下，`aria-invalid` + `aria-describedby` 关联错误文本。
- [ ] 相对时间带绝对时间的 machine-readable 属性或 title。
- [ ] loading 区域 `aria-busy`，错误区域 `role="alert"`。

动效：

- [ ] 全部动效尊重 `prefers-reduced-motion`（app.css 全局降级 + 第 04 章清单逐条降级行为）。
- [ ] 无 3 次/秒以上的闪烁内容。

## 5. 响应式断点（390 / 768 / 1440）

| 断点 | 布局基线 | 必查项 |
|---|---|---|
| 390px | 单列；gnav 收折菜单；搜索进菜单；container-px 16px | 触控目标 44px；长 ID 截断不换行；徽标可折行；表格横向滚动有提示 |
| 768px | 侧栏折到内容上方或收折；卡片网格单列；PageHeader actions 折行 | 焦点顺序不乱；Tab 可横滑且有键盘等价 |
| 1440px | 完整壳：header + sidebar 240 + 主列（内容 1152 居中） | 行长不超过 65ch（长文）；表格列不溢出 |

验收标准（对应 M13.7-10 第 8 条）：390px、768px、1440px 与系统深色模式无阻断布局问题；文本无截断丢失语义；交互无不可达元素。
