# Archive

This directory keeps superseded plans, visual captures, HTML mockups, and
prototype-only tests for historical reference. Nothing here is a production
runtime input.

## Collections

| Path | Contents |
| --- | --- |
| `roadmap/` | Pre-v2.1 roadmap and task ledger |
| `legacy/` | Superseded root-level product notes |
| `plans/` | Completed workspace plans |
| `design/m13.8-html/` | Zero-build design-book mockups and their local assets |
| `visual-baselines/m13.8/` | M13.8 screenshot baselines |
| `visual-captures/v2.1-iterations/` | Kinetic Journal iteration captures |
| `prototypes/v2.1-kinetic-journal/` | Superseded standalone v2.1 prototype |
| `tests/` | Tests that exercised archived prototypes |

The maintained design contract is [`../design/README.md`](../design/README.md).
Production implementation lives under `apps/`, `packages/`, and `scripts/`.
