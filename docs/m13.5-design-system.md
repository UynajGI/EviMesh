# M13.5 视觉方向与设计系统

## 设计原则（M13.5-A08）

EviMesh 是科研推进网络，界面应当像好的论文一样安静、克制、可验证：

1. **安静（Quiet）**——默认状态没有装饰。卡片只有发丝线边框，无投影；
   颜色只用来表达含义，不用于装饰。
2. **研究优先（Research-first）**——数据（ID、哈希、时间戳）用等宽数字
   （`tabular-nums`），保证对齐与可扫描性；陈述比修辞重要。
3. **分层而非强调（Hierarchy over emphasis）**——用间距与字重分层，而不是
   用大量加粗/高亮。一级导航不超过 6 项，主动作每屏至多一个。
4. **可访问（Accessible）**——语义色对通过 WCAG 2.2 AA（文本 4.5:1），
   焦点环 2px、在任何表面上可见，触控目标 ≥44px。

## 色彩（M13.5-B01）

受限的蓝灰系（hue 255），状态色低饱和。全部语义 Token 定义在
`apps/web/app/globals.css`，由 `test/token-contrast.test.mjs` 持续校验
light/dark 双主题下每对文本色的对比度 ≥4.5:1。

| Token | 用途 |
|---|---|
| background / foreground | 页面基底与正文 |
| card / card-foreground | 数据卡片 |
| muted / muted-foreground | 次级信息、徽标 |
| secondary / secondary-foreground | 段落眉题、次级填充 |
| accent / accent-foreground | 高亮与选中 |
| border | 发丝线分隔 |
| primary / primary-foreground | 唯一主操作 |
| destructive / destructive-foreground | 不可逆/危险操作 |
| success / warning / info | 验证结果、警示、信息状态 |

## 排版与间距（M13.5-B02）

- 字体：系统 UI 栈（sans）+ 等宽栈（mono），数据用 `tabular-nums`。
- 标题层级：页面标题 4xl/6xl → 区块标题 2xl（tracking-tight）→ 卡片标题
  font-medium。区块眉题用 `secondary-foreground` 的小字号，避免全大写加粗。
- 间距：容器 `max-w-6xl px-6`；区块间距 `mt-16`；卡片内边距 `p-5`；
  卡片网格 `gap-4`。
- 圆角：卡片 `rounded-lg`（0.5rem），徽标 `rounded-full`。

## 密度与图形

- 列表/卡片以文本为主，图形（DAG、Frontier 时间线）作为补充视图，
  必须同时提供键盘/列表替代视图。
- 空状态、错误、加载、拒绝（denied）都有明确的文案与恢复路径，
  原始 API 错误不外露。

## 落地范围（本分支）

- 完整语义 Token 集 + 对比度门禁测试（B01/B02）
- 全局焦点环与 `tabular-nums` 工具类
- 桌面/移动端 Shell（一级导航 ≤6 + 单 CTA + 移动收折，A06/B09/B10）
- 首页信息层级与排版打磨（C01 方向）
- 动作原语 Button/Link（B03）：primary/secondary/outline/ghost/destructive/link
  六变体 + loading/disabled/focus，全部走语义 Token；含 `buttonLinkVariants`
  供 `next/link` 使用，由 `test/button-primitives.test.mjs` 固化。
- 文本表单原语（B04）：Input/Textarea/Label/Help/Error/FieldGroup，Token 化、
  可组合、`aria-invalid` 显式错误态，由 `test/form-primitives.test.mjs` 固化。
- 选择原语（B05）：Checkbox/Radio/Select 用原生元素（平台键盘/读屏语义），
  Switch 用 `role="switch"` 按钮；全部 Token 化，由
  `test/selection-primitives.test.mjs` 固化。
- 反馈原语（B06）：Alert（info/success/warning/destructive 四态）、Empty、
  ErrorState（可重试）、Progress（accessible progressbar）、Skeleton，由
  `test/feedback-primitives.test.mjs` 固化；首页已应用错误可恢复 + 空状态
  模式（C01 的 loading/empty/error/retry 四态）。
- 数据原语（B07 核心）：Badge（六态）、Card/CardHeader/CardContent（平卡片 +
  发丝线）、Metadata（tabular-nums 元数据行），由
  `test/data-primitives.test.mjs` 固化。
- 浮层原语（B08 核心）：Dialog（Radix 焦点管理，Token 化表面）、Confirm
  （alertdialog，可 destructive + loading）、Tooltip（hover/键盘可达），由
  `test/overlay-primitives.test.mjs` 固化。
- 页面模板（B11 核心）：PageContainer/PageHeader/SectionHeader 统一
  eyebrow/标题/描述/动作槽与垂直节奏，覆盖 list/detail/workspace/wizard/
  settings 五类模板的地基；首页与任务看板已切换到模板，由
  `test/page-template.test.mjs` 固化。
- Claim 列表（C08）：状态徽标文本先行（非仅颜色编码）、tag/问题/活跃时间
  可扫描元数据，loading/empty/error/retry 全态，由
  `test/claim-list.test.mjs` 固化。
- Project 列表（C02）：本地搜索 + 状态筛选、状态徽标与活跃时间、创建表单
  换原语（loading/确认/错误），loading/empty/error/retry 全态，由
  `test/project-list.test.mjs` 固化。
- Question 列表（C04，新建页面）：状态徽标 + 下一步动作文案、本地搜索 +
  状态筛选，loading/empty/error/retry 全态，由
  `test/question-list.test.mjs` 固化。
- Project 工作区（C03）：Overview/Questions/Tasks/Claims/Frontier/Activity
  六 tab 上下文内切换（aria-pressed），含 FrontierTimeline 与事件流，
  由 `test/project-detail.test.mjs` 固化。
- Question 详情（C05）：Contract/修订号/项目/Frontier 关系卡 + Tasks 链接，
  loading/empty/error/retry 全态，由 `test/question-detail.test.mjs` 固化。
- Task 详情（C07）：Inputs/Outputs/Acceptance/Dependencies/Leases 同屏 +
  Attempt/租赁动作换原语（loading/disabled/错误恢复），由
  `test/task-detail.test.mjs` 固化。
