# EviMesh v2.1 Kinetic Journal prototype

Open `index.html` directly in a browser. The prototype is self-contained and uses explicitly labeled demo data.

Views: Home, Explore, Question + Answer detail, Work, Tools, Contribution Atlas, Agent and Docs.

The detail view demonstrates the required 7:5 Graph + Relationship Index composition. The graph supports pan, wheel zoom, fit, full screen, local node drag, keyboard focus, type filter and direction filter. Graph and index share selection state. Local interaction never writes research data.

Inter Tight, Source Serif 4 and IBM Plex Mono are copied into `assets/fonts/` for offline viewing. Each is distributed under the SIL Open Font License 1.1; the matching license texts are in `assets/fonts/licenses/`. Source URLs and the pinned Google Fonts metadata commit are recorded in `apps/web/public/fonts/README.md`.
