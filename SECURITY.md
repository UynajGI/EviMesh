# Security policy

## Supported versions

EviMesh is currently a public preview. Security fixes are applied to the
currently deployed preview and the latest `main` branch. Older preview builds
and unreleased local snapshots are not maintained as separate supported
versions.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, or
pull request.

If the repository's **Security** page shows **Report a vulnerability**, use
that GitHub private-reporting form. If the button is not available, email the
repository owner at `yuunagi.cn@outlook.com` with the subject
`EviMesh security report`.

Include the affected version or commit, impact, prerequisites, and the smallest
safe reproduction you can provide. Do not include live passwords, API keys,
private keys, access tokens, unnecessary personal data, or production research
content. If the report concerns an exposed credential, identify its type and
scope without copying the credential itself.

The maintainers will coordinate validation, remediation, and disclosure with
the reporter through the same private channel.
